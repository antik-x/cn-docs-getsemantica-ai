**`PgVectorStore`** 为 Semantica 提供原生于 PostgreSQL 的向量存储与相似度检索：无需专用的向量数据库。


## 概览

**`PgVectorStore`** 通过 [pgvector](https://github.com/pgvector/pgvector) 扩展提供原生的 PostgreSQL 向量存储。它支持**多种距离度量**（余弦相似度、L2/欧氏距离、内积）、索引类型（IVFFlat、HNSW），以及带过滤能力的 JSONB 元数据存储。

## 功能特性

<Check>距离度量：余弦、L2（欧氏距离）、内积</Check>
<Check>索引类型：IVFFlat 与 HNSW，用于近似最近邻检索</Check>
<Check>JSONB 元数据存储，支持过滤</Check>
<Check>基于 psycopg3/psycopg2 的连接池</Check>
<Check>批量插入、更新与删除</Check>
<Check>幂等的索引创建：多次调用均安全</Check>


## 安装

### 前置条件

1. PostgreSQL 13+，并已安装 pgvector 扩展
2. Python 依赖：`psycopg3`（推荐）或 `psycopg2-binary`、`pgvector`

## 用法

### 基本用法

```python
from semantica.vector_store import PgVectorStore
import numpy as np

# Initialize store
store = PgVectorStore(
    connection_string="postgresql://postgres:postgres@localhost:5432/semantica",
    table_name="document_vectors",
    dimension=768,
    distance_metric="cosine",
    pool_size=10
)

# Add vectors
vectors = [np.random.rand(768).astype(np.float32) for _ in range(100)]
metadata = [{"doc_id": i, "category": "article"} for i in range(100)]
ids = store.add(vectors, metadata)

# Search
query = np.random.rand(768).astype(np.float32)
results = store.search(query, top_k=10)

# Results format: [{"id": "...", "score": 0.95, "metadata": {...}}, ...]
for result in results:
    print(f"ID: {result['id']}, Score: {result['score']:.4f}")

# Close store
store.close()
```

### 上下文管理器

```python
with PgVectorStore(
    connection_string="postgresql://...",
    table_name="vectors",
    dimension=768,
    distance_metric="cosine"
) as store:
    vectors = [np.random.rand(768).astype(np.float32)]
    ids = store.add(vectors, [{"source": "test"}])
    # Store automatically closed on exit
```

### 元数据过滤

```python
# Search with metadata filter
results = store.search(
    query_vector,
    top_k=10,
    filter={"category": "science", "published": True}
)
```

### 更新与删除

```python
# Update vectors and metadata
new_vectors = [np.random.rand(768).astype(np.float32)]
new_metadata = [{"updated": True}]
store.update(["vec_0"], new_vectors, new_metadata)

# Update metadata only
store.update(["vec_0"], metadata=[{"tag": "updated"}])

# Delete vectors
store.delete(["vec_0", "vec_1"])
```

### 按 ID 检索

```python
results = store.get(["vec_0", "vec_1"])
# Returns: [{"id": "vec_0", "vector": np.array(...), "metadata": {...}}, ...]
```

### 索引创建

```python
# Create HNSW index for approximate nearest neighbor search
store.create_index(
    index_type="hnsw",
    params={"m": 16, "ef_construction": 64}
)

# Create IVFFlat index
store.create_index(
    index_type="ivfflat",
    params={"lists": 100}
)
```

索引创建是幂等的：多次调用均安全。

## 距离度量

| 度量 | 运算符 | 说明 | 使用场景 |
| :-------- | :---------- | :------------- | :---------- |
| `cosine` | `<=>` | 余弦距离（1 - 余弦相似度） | 语义相似度、文本嵌入（Embedding） |
| `l2` | `<->` | 欧氏距离 | 几何距离、聚类 |
| `inner_product` | `<#>` | 负内积 | 最大内积检索 |

**注意**：无论使用哪种度量，`search()` 返回的分数都会归一化为相似度（越高越好）。

## 索引类型

<Tabs>
  <Tab title="HNSW">
    **Hierarchical Navigable Small World**：最适合有高召回率需求的高维向量。

    | | |
    | :-- | :-- |
    | **优点** | 检索快、召回率良好、支持增量构建 |
    | **缺点** | 内存占用更高、构建时间更长 |

    ```python
    store.create_index(index_type="hnsw", params={
        "m": 16,               # connections per layer (default: 16)
        "ef_construction": 64  # build-time accuracy/speed tradeoff (default: 64)
    })
    ```
  </Tab>
  <Tab title="IVFFlat">
    **Inverted File with Flat Index**：最适合内存受限环境下的大型数据集。

    | | |
    | :-- | :-- |
    | **优点** | 内存占用更低、速度/精度可调 |
    | **缺点** | 需要训练数据、增量更新较慢 |

    ```python
    store.create_index(index_type="ivfflat", params={
        "lists": 100  # number of inverted lists (default: 100)
    })
    ```

    <Note>IVFFlat 在训练开始前，向量数量至少要达到 `lists` 的数量。</Note>
  </Tab>
</Tabs>

## 迁移说明

### 从其他向量存储迁移

```python
# Export from existing store
from semantica.vector_store import FAISSStore

faiss_store = FAISSStore(dimension=768)
# ... load existing index

# Migrate to PgVectorStore
pg_store = PgVectorStore(
    connection_string="postgresql://...",
    table_name="migrated_vectors",
    dimension=768,
    distance_metric="cosine"
)

# Get all vectors from source
all_ids = list(faiss_store.index.vector_ids)
all_vectors = [...]  # Get vectors from source
all_metadata = [faiss_store.index.metadata.get(id, {}) for id in all_ids]

# Batch insert
pg_store.add(all_vectors, all_metadata, all_ids)
```

## 错误处理

常见错误与解决方法：

| 错误 | 原因 | 解决方法 |
| :------- | :------- | :---------- |
| `ProcessingError: pgvector extension is not installed` | PostgreSQL 中未安装 pgvector | 运行 `CREATE EXTENSION vector;` |
| `ValidationError: Unsupported distance metric` | 度量无效 | 使用：`cosine`、`l2`、`inner_product` |
| `ValidationError: dimension mismatch` | 向量维度与存储维度不一致 | 确保维度一致 |
| `ProcessingError: Failed to initialize connection pool` | 连接问题 | 检查连接字符串与网络 |

## 性能调优

1. **大型数据集请使用索引**（向量数超过 10k）
2. **调优 HNSW 参数**：更高的 `m` 与 `ef_construction` 意味着更高的召回率、更慢的构建
3. **连接池大小**：根据并发工作负载设置
4. **批量操作**：使用 `add()` 传入列表，而非逐条插入
