## 系统要求

| 组件 | 最低要求 | 推荐配置 |
| :--------- | :------- | :----------- |
| Python | 3.8 | 3.11+ |
| 操作系统 | Windows / Linux / Mac | Linux / Mac |
| 内存 | 4 GB | 16 GB+ |
| 存储 | 2 GB | 20 GB+（模型与数据） |


## 基础安装

```bash
pip install semantica
```

如需安装全部可选依赖：

```bash
pip install semantica[all]
```

### 验证

```bash
python -c "import semantica; print(semantica.__version__)"
```

## 从源码安装

如需最新的开发版本，或想参与贡献：

```bash
git clone https://github.com/semantica-agi/semantica.git
cd semantica

pip install -e .         # core only
pip install -e ".[all]"  # all extras
pip install -e ".[dev]"  # dev tools (pytest, black, etc.)
```

如果 PyPI 发布版本有问题，可直接从 main 分支安装：

```bash
pip install git+https://github.com/semantica-agi/semantica.git@main
```


## 故障排除

<AccordionGroup>

<Accordion title="ModuleNotFoundError: No module named 'semantica'" icon="circle-xmark">

确认你处于正确的虚拟环境中：

```bash
pip list | grep semantica
pip install --upgrade semantica
```

</Accordion>

<Accordion title="安装时因依赖错误而失败" icon="triangle-exclamation">

```bash
pip install --upgrade pip
pip install build wheel
pip install semantica --no-deps  # install core first, then add extras
```

</Accordion>

<Accordion title="GPU 依赖安装失败" icon="bolt">

先安装纯 CPU 版本，再叠加 GPU 支持：

```bash
pip install semantica
pip install semantica[gpu]
```

</Accordion>

<Accordion title="权限被拒绝" icon="lock">

```bash
pip install --user semantica  # or use a virtual environment
```

</Accordion>

<Accordion title="Windows 上 [all] 安装失败" icon="windows">

该问题已在 **v0.5.0** 中修复。请升级到最新发布版：

```bash
pip install --upgrade semantica
```

</Accordion>

<Accordion title="Windows 上启动时出现 PyTorch DLL 错误" icon="windows">

请安装 [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)。这是 Windows 的系统依赖，而不是 Semantica 的 bug。

</Accordion>

</AccordionGroup>
