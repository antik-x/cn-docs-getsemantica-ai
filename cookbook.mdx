## 核心教程

掌握 Semantica 框架的必备指南。

- **[欢迎来到 Semantica](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/01_Welcome_to_Semantica.ipynb)** —— 以交互方式介绍该框架的核心理念与全部模块。主题：框架概览、架构 · *入门*
- **[数据摄取](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/02_Data_Ingestion.ipynb)** —— 从文件、Web、数据库、流、订阅源、仓库、电子邮件与模型上下文协议（MCP）加载数据。主题：FileIngestor、WebIngestor、DBIngestor · *入门*
- **[文档解析](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/03_Document_Parsing.ipynb)** —— 从 PDF、DOCX、HTML 等复杂格式中抽取干净文本。主题：OCR、PDF 解析、文本抽取 · *入门*
- **[数据规范化](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/04_Data_Normalization.ipynb)** —— 用于清洗、规范化与准备文本的流水线。主题：文本清洗、Unicode、格式化 · *入门*
- **[实体抽取](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/05_Entity_Extraction.ipynb)** —— 使用命名实体识别（NER）识别人物、组织与自定义实体。主题：NER、spaCy、LLM 抽取 · *入门*
- **[关系抽取](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/06_Relation_Extraction.ipynb)** —— 发现并分类实体之间的关系。主题：关系分类、依存句法分析 · *入门*
- **[嵌入生成](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/12_Embedding_Generation.ipynb)** —— 创建并管理用于语义搜索的向量嵌入（Embedding）。主题：Embeddings、OpenAI、HuggingFace · *中级*
- **[向量存储](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/13_Vector_Store.ipynb)** —— 搭建用于相似度搜索与检索的向量存储。*中级*
- **[图存储](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/09_Graph_Store.ipynb)** —— 将知识图谱持久化到 Neo4j 或 FalkorDB。主题：Neo4j、Cypher、持久化 · *中级*
- **[本体](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/14_Ontology.ipynb)** —— 定义领域 Schema 与本体（Ontology），为数据建立结构。主题：OWL、RDF、Schema 设计 · *中级*
- **[种子数据](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/25_Seed_Data.ipynb)** —— 在抽取运行之前，用可信的 CSV、JSON、数据库与 API 来源引导构建知识图谱。主题：SeedDataManager、基础图谱 · *中级*


## 进阶概念

深入了解高级特性、自定义与复杂工作流。

- **[进阶抽取](https://github.com/semantica-agi/semantica/blob/main/cookbook/advanced/01_Advanced_Extraction.ipynb)** —— 自定义抽取器、基于 LLM 的抽取与复杂模式匹配。主题：自定义模型、正则表达式、LLM · *高级*
- **[进阶图分析](https://github.com/semantica-agi/semantica/blob/main/cookbook/advanced/02_Advanced_Graph_Analytics.ipynb)** —— 中心性、社区检测与寻路算法。主题：PageRank、Louvain、最短路径 · *高级*
- **[进阶上下文工程](https://github.com/semantica-agi/semantica/blob/main/cookbook/advanced/11_Advanced_Context_Engineering.ipynb)** —— 使用 FAISS 与 Neo4j、面向 AI 智能体的生产级记忆系统。主题：智能体记忆、GraphRAG、实体注入 · *高级*
- **[完整可视化套件](https://github.com/semantica-agi/semantica/blob/main/cookbook/advanced/03_Complete_Visualization_Suite.ipynb)** —— 可交互、达到发表级别的图谱可视化。主题：PyVis、NetworkX、D3.js · *中级*
- **[冲突解决](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/17_Conflict_Detection_and_Resolution.ipynb)** —— 处理来自多个来源的矛盾信息的策略。主题：真值发现、投票、置信度 · *高级*
- **[多格式导出](https://github.com/semantica-agi/semantica/blob/main/cookbook/advanced/05_Multi_Format_Export.ipynb)** —— 导出到 RDF、OWL、JSON-LD 与 NetworkX 格式。主题：序列化、互操作性 · *中级*
- **[多源集成](https://github.com/semantica-agi/semantica/blob/main/cookbook/advanced/06_Multi_Source_Data_Integration.ipynb)** —— 将来自不同来源的数据合并为统一的图谱。主题：实体消解、合并、融合 · *高级*
- **[推理与推断](https://github.com/semantica-agi/semantica/blob/main/cookbook/advanced/08_Reasoning_and_Inference.ipynb)** —— 运用逻辑推理从既有事实中推断出新知识。主题：逻辑规则、推理引擎 · *高级*
- **[时序知识图谱](https://github.com/semantica-agi/semantica/blob/main/cookbook/advanced/10_Temporal_Knowledge_Graphs.ipynb)** —— 对随时间变化的数据进行建模与查询。主题：时间序列、时序逻辑、Allen 代数 · *高级*
- **[溯源追踪](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/22_Provenance_Tracking.ipynb)** —— 审计级、对齐 W3C PROV-O 的溯源（Provenance）追踪，记录每个实体、关系与文本块来自何处。主题：PROV-O、血缘、校验和、失效 · *高级*
- **[Reasoning 模块](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/23_Reasoning.ipynb)** —— 使用前向链、后向链与 Datalog 策略从既有事实推导新知识。主题：Reasoner、Datalog、解释 · *高级*
- **[变更管理](https://github.com/semantica-agi/semantica/blob/main/cookbook/introduction/24_Change_Management.ipynb)** —— 面向知识图谱与本体的版本管理、审计追踪与数据完整性检查。主题：ChangeLogEntry、版本存储、数据完整性 · *高级*


## 如何运行

<Steps>
  <Step title="安装 Semantica">
    ```bash
    pip install semantica[all]
    pip install jupyter
    ```
  </Step>
  <Step title="克隆仓库（可选，用于源码安装）">
    ```bash
    git clone https://github.com/semantica-agi/semantica.git
    cd semantica
    pip install -e ".[all]"
    pip install jupyter
    ```
  </Step>
  <Step title="启动 Jupyter">
    ```bash
    jupyter notebook
    ```
  </Step>
</Steps>

<Tip>
  你也可以使用 Docker 运行实战手册：

  ```bash
  docker run -p 8888:8888 semantica/semantica-cookbook
  ```
</Tip>
