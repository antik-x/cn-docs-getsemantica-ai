**`semantica-explorer`** 是一个用于知识图谱（Knowledge Graph）探索的**交互式浏览器仪表盘**。你给它一个图谱文件，它会启动本地服务器并打开一个浏览器标签页，你可以在其中搜索节点、查找路径、查看溯源（Provenance）、运行图分析——启动之后无需编写任何代码。

本页涵盖从零到启动运行知识探索器所需的全部内容。完整的 REST API 参考与端点目录，参见[知识探索器参考](reference/explorer)。


## 前提条件

知识探索器依赖 FastAPI 与 uvicorn，两者不包含在基础安装中：

```bash
pip install semantica[explorer]
```

<Note>
  只执行 `pip install semantica` 并不够。在缺少 `[explorer]` 可选依赖的情况下运行 `semantica-explorer`，会立即打印错误并以退出码 1 退出。
</Note>

验证：

```bash
semantica-explorer --help
```

你应该会看到包含四个可用选项的用法信息。如果看到 `command not found`，请先激活你的虚拟环境。PATH 相关问题见[CLI 配置](cli-setup#troubleshooting)。


## 最小端到端示例

以下四个步骤就是让知识探索器运行起来所需的全部操作：

```python
from semantica.context import ContextGraph

# 1. Create a graph
graph = ContextGraph()

# 2. Add a node
graph.add_node("python", "language", content="Python programming language")

# 3. Save to disk
graph.save_to_file("my_graph.json")
```

```bash
# 4. Launch Explorer
semantica-explorer --graph my_graph.json
```

浏览器会在 `http://127.0.0.1:8000` 打开。健康检查端点可确认服务器已就绪：

```bash
curl http://127.0.0.1:8000/api/health
# {"status": "ok"}
```


## 步骤 1：构建并保存 ContextGraph

知识探索器从磁盘上的 JSON 文件加载图谱。你需要先创建这个文件。

<Steps>
  <Step title="构建图谱">
    ```python
    from semantica.context import ContextGraph

    graph = ContextGraph()

    # add_node(node_id, node_type, content=None, **properties)
    graph.add_node("python",  "language",  content="Python programming language")
    graph.add_node("fastapi", "framework", content="FastAPI web framework")
    graph.add_node("guido",   "person",    content="Guido van Rossum")

    # add_edge(source_id, target_id, edge_type="related_to", weight=1.0, **properties)
    graph.add_edge("python",  "fastapi", "enables")
    graph.add_edge("guido",   "python",  "created")
    ```
  </Step>
  <Step title="保存为 JSON 文件">
    ```python
    graph.save_to_file("my_graph.json")
    ```

    `save_to_file` 会将一个包含 `graph_id`、`nodes`、`edges` 与 `links` 的 JSON 对象写入指定路径。
  </Step>
  <Step title="验证文件可加载（可选的完整性检查）">
    ```python
    from semantica.context import ContextGraph

    check = ContextGraph()
    check.load_from_file("my_graph.json")
    print(check.stats())
    # {
    #   "node_count": 3,
    #   "edge_count": 2,
    #   "node_types": {"language": 1, "framework": 1, "person": 1},
    #   "edge_types": {"enables": 1, "created": 1},
    #   "density": ...
    # }
    ```

    如果这段代码运行无报错，知识探索器就能成功加载该文件。
  </Step>
</Steps>

<Tip>
  已经有流水线运行产出的图谱？直接跳到步骤 2。唯一的要求是该文件通过 `ContextGraph.save_to_file()` 保存。
</Tip>


## 步骤 2：启动知识探索器

```bash
semantica-explorer --graph my_graph.json
```

启动时会输出：

```
✓ Graph loaded: 3 nodes, 2 edges
╭─ Semantica Explorer · http://127.0.0.1:8000 ─╮
│  API docs  http://127.0.0.1:8000/docs         │
│  Health    http://127.0.0.1:8000/api/health   │
╰───────────────────────────────────────────────╯
```

服务器启动后不久，浏览器会自动在 `http://127.0.0.1:8000` 打开。


## CLI 选项

`semantica-explorer` 恰好接受四个选项：

| 选项 | 短选项 | 默认值 | 说明 |
| :---- | :----- | :------- | :----------- |
| `--graph` | `-g` | *(**必填**)* | ContextGraph JSON 文件的路径 |
| `--port` | `-p` | `8000` | 服务器绑定的端口 |
| `--host` |: | `127.0.0.1` | 服务器绑定的主机 |
| `--no-browser` |: | 关闭 | 不自动打开浏览器标签页 |

没有用于身份验证、日志级别或 TLS 的选项。CLI 中并未实现这些功能。

### 示例

```bash
# Minimal: local only, port 8000, browser opens automatically
semantica-explorer --graph my_graph.json

# Short flags
semantica-explorer -g my_graph.json -p 8080

# Expose on the network so other machines can connect
semantica-explorer --graph my_graph.json --host 0.0.0.0 --port 8080

# Headless: skip the auto-open and navigate manually
semantica-explorer --graph my_graph.json --no-browser
```

<Warning>
  `--host 0.0.0.0` 会让知识探索器在所有网络接口上可达。从 v0.6.5 起，Explorer API 要求提供 `SEMANTICA_API_KEY`（通过 `X-API-Key` 请求头发送），未配置时会失败关闭并返回 `503`；只有显式设置 `SEMANTICA_ALLOW_ANONYMOUS=true` 时才可能匿名访问。请只在可信的私有网络中这样使用。
</Warning>


## 浏览器访问

服务器运行起来之后：

| URL | 你会得到 |
| :--- | :------------ |
| `http://127.0.0.1:8000` | 交互式仪表盘 |
| `http://127.0.0.1:8000/docs` | Swagger UI：所有 REST 端点，均可交互 |
| `http://127.0.0.1:8000/api/health` | 健康检查：`{"status": "ok"}` |

浏览器标签页会在启动后不久打开。如果没有打开，请手动前往该 URL，或传入 `--no-browser` 后自行打开。


## 以 Python 模块运行

如果 `semantica-explorer` 不在 `PATH` 中，请使用模块形式：

```bash
python -m semantica.explorer --graph my_graph.json --port 8080
```


## 常见启动错误

<AccordionGroup>

<Accordion title="错误：找不到图谱文件" icon="file-circle-xmark">

传给 `--graph` 的路径必须指向一个已存在的文件。CLI 在加载任何内容之前会用 `os.path.isfile()` 进行检查。

```bash
# Confirm the file exists
ls my_graph.json                                          # Linux / Mac
dir my_graph.json                                         # Windows

# Use the full path if needed
semantica-explorer --graph /absolute/path/to/my_graph.json
```

</Accordion>

<Accordion title="错误：需要 uvicorn" icon="triangle-exclamation">

未随基础包一起安装 `[explorer]` 可选依赖：

```bash
pip install semantica[explorer]
```

</Accordion>

<Accordion title="知识探索器启动了，但显示零个节点" icon="circle-xmark">

文件加载了，但其中没有节点。用 Python 验证：

```python
from semantica.context import ContextGraph
g = ContextGraph()
g.load_from_file("my_graph.json")
print(g.stats())  # check node_count
```

`node_count` 为 `0` 表示图谱在添加任何节点之前就被保存了。请确保先调用 `add_node()`，再调用 `save_to_file()`。

</Accordion>

<Accordion title="从其他机器连接被拒绝" icon="network-wired">

默认的 `--host 127.0.0.1` 只接受来自同一台机器的连接。要允许远程访问：

```bash
semantica-explorer --graph my_graph.json --host 0.0.0.0
```

</Accordion>

<Accordion title="浏览器标签页没有打开" icon="browser">

在无界面（headless）、SSH 与容器环境中这是正常现象。传入 `--no-browser` 以抑制该警告，然后在能够通过网络访问服务器的浏览器中打开 `http://127.0.0.1:8000`。

</Accordion>

</AccordionGroup>


## 知识探索器提供什么

运行之后，知识探索器会提供一套 REST API 与仪表盘，可用于：

- **节点与边搜索**：按 ID、类型和内容对所有节点进行索引搜索
- **邻域扩展**：检查最多可配置跳数深度的邻居节点
- **路径查找**：任意两个节点之间的 BFS 最短路径
- **图分析**：中心性、社区检测、连通性
- **决策与溯源**：查询已记录的决策及其因果链
- **导入 / 导出**：上传 JSON 或 CSV 以扩展图谱；下载当前状态
