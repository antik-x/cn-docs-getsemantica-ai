## 这意味着什么

**你可以：**

<Check>将 Semantica 用于商业目的：业务使用免费</Check>
<Check>修改源代码</Check>
<Check>分发副本或衍生作品</Check>
<Check>在专有软件中使用</Check>

**你必须：**

- 在副本中保留版权声明
- 在分发中包含 MIT 许可证文本

<Warning>**无担保**：作者对损害不承担责任，也不对你如何使用该软件负责。</Warning>


## 商业使用

Semantica 可完全免费用于商业用途。无需署名（但如能署名，我们不胜感激）。


## 第三方依赖

Semantica 使用的开源库均采用兼容的许可证：

| 库 | 许可证 |
| :--------- | :--------- |
| Python | PSF License |
| NumPy, Pandas | BSD |
| spaCy | MIT |
| Transformers | Apache 2.0 |
| RDFLib | BSD |


## 贡献

向 Semantica 贡献即表示你同意：你的贡献将基于同样的 MIT 许可证进行许可。
